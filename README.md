# SW-Watch — Severe Weather Watch 劇烈天氣監控平台

整合雷達回波、衛星雲圖（可見光／水氣／紅外線）、測站觀測、海象（浮標站、潮位站）、雨量圖、ECMWF 預報（台灣附近 84 小時）與颱風（官方＋系集）預測路徑的網頁監控平台，所有圖層都可以選擇歷史時間。

- 資料處理：`pipeline/`（Python，本機或樹莓派排程執行，輸出靜態檔到 `data/`）
- 前端：`web/`（JS + MapLibre GL JS；衛星雲圖、ECMWF 預報、雷達回波、測站、氣象署颱風路徑、系集路徑、時間軸、同步切換）
- 部署（排程電腦 + Cloudflare R2 + GitHub Pages）：[部署說明.md](部署說明.md)
- 設計與進度：[設計log.md](設計log.md)

## 執行

```bash
pip install -r requirements.txt
cp .env.example .env          # 填入氣象資料開放平臺授權碼 CWA_KEY（與 R2 金鑰，見部署說明）
python -m pipeline.scheduler --once   # 各資料抓一次
python -m pipeline.scheduler          # 常駐排程
```

本機看網頁（在專案根目錄）：

```bash
python -m http.server 8765
# 瀏覽器開 http://127.0.0.1:8765/web/
```

## 颱風／豪雨事件一鍵產出（`pipeline.event_report`）

颱風或豪雨過後，執行一行指令，就會產生統計圖表、縮時影片和 YouTube 用的標題說明：

```bash
pip install matplotlib imageio-ffmpeg openpyxl pyshp
# 颱風
python -m pipeline.event_report --kind typhoon --name 薔琵颱風 --start "2026-10-22 00:00" --end "2026-10-24 20:00"
# 豪雨
python -m pipeline.event_report --kind rain --name 1025豪雨 --start "2026-10-25 00:00" --end "2026-10-26 12:00"
```

- **時間**：都是台灣時間。`--end` 省略 = 最新一筆測站快照。
- **`--kind`、`--name` 必填**：事件種類和名稱自己給，名稱會用在標題和資料夾名稱。
  - `typhoon`：做 5 支影片（雷達、雷達+颱風、衛星日夜+颱風、颱風+測站陣風、颱風+測站平均風）。總結先列風，再附上期間內中心進入本島 500 km 內的颱風生命史。
  - `rain`：做 2 支影片（雷達、衛星日夜），總結先列雨量。
  - 衛星只保留 5 天。超過 5 天才做影片的話，要先用 `event_archive --satellite` 存起來。
- **兩種事件的總結都有**：
  - 最大陣風、最大平均風。
  - 總累積雨量。
  - 最大時雨量，以及 3、6、12、24 小時雨量。
  - 達到氣象署雨量分級的站數。
- **短時雨量的時間窗**：只算整段都在期間內的時間窗。所以事件期間短於 24 小時，就沒有 24 小時雨量。
- **輸出**：全部放在 `charts/{起}_{迄}_{名稱}/`。

| 檔案 | 內容 |
|---|---|
| `rain_total.png`、`rain_total_station.png` | 總累積雨量（內插圖、測站點） |
| `wind_max.png`、`gust_max.png` | 最大平均風、最大陣風 |
| `rain_total.csv`、`wind_max.csv`、`rain_max.csv` | 各站數值（`rain_max` 是最大時雨量、3、6、12、24 小時雨量） |
| `county_*.csv`、`county_stats.xlsx` | 各縣市最大值（總雨量、平均風、陣風、時雨量、3、6、12、24 小時雨量） |
| `*.mp4` | 縮時影片 |
| `summary.txt` | 事件總結：颱風生命史與最接近台灣的時間、各項排行、達氣象署雨量分級的站數 |
| `youtube.txt` | 每支影片的標題＋說明（含圖例、雷達缺漏時段、事件總結），可直接貼上 |

其他參數：
- `--videos radar,radar_ty,sat,sat_ty,gust,wind`：指定要做哪幾支影片。`sat` 是衛星日夜，`sat_ty` 再加颱風路徑。
- `--no-video`：只做統計和摘要，幾分鐘就跑完。
- `--top 6`：排行列幾名。
- `--fps 8`、`--local`、`--shp`：同 `radar_video`。

執行時要注意：
- 4 支三天的影片要跑比較久，而且要在前景執行。
- `summary.txt` 是自動整理的即時資料，數值異常的測站（例如陣風特別高）和是否登陸，請先對照氣象署的報告。

只要其中一部分，也可以分開執行：
- 統計圖表：`python -m pipeline.event_stats --start ... [--end ...]`，輸出到 `charts/{起}_{迄}/`。
- 單支影片：用下面的 `radar_video`。

## 事件觀測資料歸檔（`pipeline.event_archive`）

排程的清理規則會刪掉舊資料，本機和 R2 都一樣：測站、雷達、雨量等資料只留 `KEEP_DAYS` 天（預設 10 天），超過就全部刪除；衛星雲圖只留 `SAT_KEEP_DAYS` 天（預設 5 天）。事件結束後要在期限內歸檔。要永久保留某個事件的觀測資料，請手動執行：

```bash
python -m pipeline.event_archive --name 薔琵颱風 --start "2026-10-22 00:00" --end "2026-10-24 20:00" [--web] [--satellite]
```

| 存什麼 | 內容 | 三天約多大 |
|---|---|---|
| 預設 | 測站 10 分鐘快照、雷達整合回波、氣象署雨量格點、颱風路徑與颱風消息（颱風往前多存一天）、海象每小時快照 | 約 100 MB |
| `--web` | 網頁圖層用的衍生資料：測站累積 `stations/agg_*`、雨量內插 `rain/idw/*` | 再加約 200 MB |
| `--satellite` | 衛星雲圖 B03 / B07 / B08 / B13。只保留 5 天，事件結束後要盡快執行 | 數 GB |

- **壓縮**：雷達、雨量、衛星、測站累積這幾種原本就是壓縮檔，照原樣存。測站快照和颱風路徑原本沒壓縮，歸檔時會壓縮成 `.json.gz`，測站快照約剩原本的 1/4。

- **存放位置**：`archive/{起}_{迄}_{名稱}/`，目錄結構同 `data/`，每層有自己的 `index.json`，另有一個 `event.json` 記錄事件資訊。
  - 這個資料夾不進 git，`cleanup` 也不會動到。
- **資料來源**：本機 `data/` 有的直接複製，沒有的從 R2 下載。已經存過的檔會跳過，中斷後重跑會接著做。
- **上傳 R2**：`.env` 有 R2 金鑰時，會另外上傳到 R2 的 `events/{起}_{迄}_{名稱}/`，並更新 `events/index.json`。
  - 加 `--no-upload` 就不上傳。
  - 沒有金鑰的電腦只會存在本機。到排程電腦再執行一次同樣的指令，就會補上傳。
- **事後重做**：`event_stats`、`radar_video`、`event_report` 都會自動讀 `archive/`。原始資料被清掉後，還是能重做統計和影片，可以加 `--local` 只用本機資料。

## 海象（浮標站、潮位站）

資料來源是氣象署 O-B0075-001「海象監測資料－48 小時浮標站與潮位站海況監測資料」，每小時一筆，站名和座標來自 O-B0076-001。

- **排程**：每小時整點後第 5–55 分，每 5 分檢查一次，抓到新的一小時就停。
  - 平常只抓最近 4 小時（約幾十 KB）。
  - 本機沒有資料或中斷超過 3 小時，就抓整份 48 小時把缺的補齊。
  - 這個產品只能用 REST API，每次檢查都算一次會員次數，一天約 100–200 次。
- **輸出**：
  - `data/marine/{時間}.json`：每小時一個快照，一個約 10 KB，跟測站一樣保留 `KEEP_DAYS` 天。
  - `data/marine/recent.json.gz`：近 48 小時各站時序，給網頁資訊卡畫圖。
- **網頁「海象（浮標／潮位）」圖層**：
  - 可選浪高、波浪週期、潮高、海溫、風速、最大陣風、海流、氣溫、氣壓。
  - 站種可勾選：◆ 浮標（含浮球式波浪站）、■ 潮位站、⬢ 岸邊氣象站。變數分「海況」和「海上氣象」兩組。
  - 和地面測站的區隔：海上符號一律藍框，數值藍色斜體；形狀代表站種。
  - 海上氣象（風速、陣風、氣溫、氣壓）：色階和地面測站相同，方便比較。風速用和地面相同的箭頭，只是加藍框。
  - 海況專用符號：浪高 = 寬箭頭（指向浪前進方向，浪越高越大）；潮高 = ▲ 漲潮／▼ 退潮；海流 = 細長箭頭（指向流去方向，越快越大）。
  - 浪高依浪級分色：小浪 1–2 m、中浪 2–3 m、大浪 3–6 m、巨浪 6 m 以上。地圖數值旁和資訊卡會標出浪級。
  - 「顯示」可選當下值、過去最大、過去最小（1–72 小時或自訂區段），和測站一樣。最大／最小在地圖數值後標發生時間（@10/23 22:00），浪、風、海流的箭頭用發生那一小時的方向。資料每小時一筆，所以最大／最小是逐時觀測裡的最大／最小。
  - 同步模式顯示時間軸所在的整點。點站會開資訊卡，看當下各項觀測和近 48 小時折線圖；浪高圖上有浪級分界虛線。
- **潮高基準**：本島潮位站是臺灣高程基準（基隆平均海水面），離島和海上觀測樁是當地平均海水面，兩者不能直接比較。

## 雷達／颱風／測站風動畫（`pipeline.radar_video`）

把一段期間的雷達整合回波，或颱風路徑與測站風，做成縮時 MP4（每 10 分鐘一格）。

- **畫面**：4:3（1600×1200），左上角有標題、時間（台灣時間）與資料來源。
- **底圖**：Natural Earth 陸地加 `shp/TWN_CITY` 縣市界。
- **回波色階**：與網頁相同，畫面上不放色階，< 0 dBZ 不畫。

```bash
pip install matplotlib imageio-ffmpeg     # imageio-ffmpeg 內含 ffmpeg

# 單純雷達回波
python -m pipeline.radar_video --start "2026-10-22 00:00" --end "2026-10-24 20:00"
# 雷達 + 颱風路徑與暴風圈
python -m pipeline.radar_video --start "2026-10-22 00:00" --end "2026-10-24 20:00" --typhoon
# 衛星日夜（白天 B03 可見光、夜間 B07 短波紅外，同網頁「日夜」頻道）+ 颱風路徑
python -m pipeline.radar_video --start "2026-10-22 00:00" --end "2026-10-24 20:00" --sat --typhoon
# 不畫雷達：颱風 + 測站平均風（加 --gust 改陣風）
python -m pipeline.radar_video --start "2026-10-22 00:00" --end "2026-10-24 20:00" --no-radar --typhoon --wind [--gust]
# 只輸出一張 PNG 先看畫面（可給時間；省略 = 最新一筆）
python -m pipeline.radar_video --preview "2026-10-24 00:00" --typhoon
```

| 參數 | 說明 |
|---|---|
| `--start` / `--end` | 台灣時間 `YYYY-MM-DD HH:MM`。`--end` 省略 = 最新一筆。 |
| `--preview [時間]` | 只輸出一張 PNG，不做影片。 |
| `--fps` | 每秒格數，預設 8（三天約 48 秒）。 |
| `--gif` | 另外輸出 GIF。 |
| `--typhoon` | 疊加颱風路徑與暴風圈，檔名加 `_ty`。 |
| `--wind` | 疊加測站平均風，檔名加 `_wind`；加 `--gust` 改畫陣風，檔名改 `_gust`。 |
| `--no-radar` | 不畫雷達，畫面放大到台灣本島。時間改用測站快照，檔名開頭改 `station_`。 |
| `--sat` | 改畫衛星日夜：依每個位置的太陽仰角，白天用 B03 可見光、夜間用 B07 短波紅外，0°–10° 之間漸變。時間跟 B07，範圍比雷達大約 1.3 倍（`EXTENT_SAT`），海岸和縣市界改成淡黃色，檔名開頭改 `sat_`。 |
| `--local` | 只用本機 `data/`，不從 R2 下載。 |
| `--shp` | `TWN_CITY` 所在資料夾，預設 `shp/`。 |

**颱風**（`--typhoon`）
- 路徑只畫氣象署實際定位：黑線，每個定位一點，定位之間不內插。
- 紅點是當下的颱風中心。
- 黃圈、紅圈是 7 級、10 級暴風圈，取平均半徑的正圓，只畫外框。
- 不畫預報路徑。

**測站風**（`--wind`）
- 箭頭指向風吹去的方向，顏色和長度依蒲福風級，畫面底部有 0–17 級的橫式色階。
- 靜風或沒有風向畫成小圓點。
- 只畫觀測時間在畫面時間前 60 分鐘內的測站，整點那格也包含前一小時的觀測。
- 不含日本氣象廳測站。

**資料與輸出**
- 本機 `data/` 沒有的檔，自動從 R2 下載並快取在 `pipeline/.cache/`。
- 雷達缺漏的時段會略過。
- 輸出到 `charts/radar/`，檔名是 `{radar|station}_{開始}_{結束}[_ty][_wind|_gust].mp4`。
- MP4 寫檔要在前景執行。在背景執行時，ffmpeg 會出現 WinError 6。

資料來源：中央氣象署開放資料平臺、NOAA Himawari-9（AWS Open Data）、ECMWF Open Data、NOAA NOMADS、Google DeepMind WeatherLab。
